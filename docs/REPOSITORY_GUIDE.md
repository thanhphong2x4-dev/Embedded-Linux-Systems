# Embedded Linux Systems - Repository Guide

## Project structure

- LAB01: Linux Kernel, U-Boot, BusyBox and Initramfs.
- LAB02: Linux character driver, procfs, sysfs and flash storage.
- LAB03: Debugging, memory analysis and performance tools.
- ASSIGNMENT_01: Assignment 1 materials.
- ASSIGNMENT_02: Assignment 2 materials.

## Navigation

Each lab has its own directory containing source files,
configuration files, documentation or experimental results.

## Repository maintenance

Use meaningful Git commits to record changes.
Review modified files before committing.
Keep source code and technical documentation organized.
