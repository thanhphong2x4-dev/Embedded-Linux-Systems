## Analysis workflow

1. Review the standard latency measurements.
2. Review the stress-test measurements.
3. Compare latency distributions.
4. Examine the histogram.
5. Inspect system-call traces using strace logs.
6. Record observations supported by the results.

## Interpretation

Latency measurements can help identify timing variation.

System-call traces can help explain application behavior.

Performance conclusions should be based on measured data.
