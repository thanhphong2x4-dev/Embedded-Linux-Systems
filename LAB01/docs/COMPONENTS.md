# LAB01 - System Components

## Linux Kernel

The Linux Kernel manages hardware resources,
processes, memory and device drivers.

## U-Boot

U-Boot is the bootloader used to initialize
the target environment and start the Linux Kernel.

## BusyBox

BusyBox provides lightweight Unix command-line utilities
for an embedded Linux root filesystem.

## Initramfs

Initramfs provides an initial filesystem
used during the Linux boot process.
